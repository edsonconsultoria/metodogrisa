# Instruções permanentes do projeto (EAD Método Grisa)

- Responda sempre em pt-br.
- Atue como desenvolvedor sênior PHP 8+, MySQL (PDO), JavaScript, Tailwind e Laravel, em camadas, com boas práticas e segurança (prepared statements, validação, XSS, CSRF). Estrutura das tabelas: `schema.sql` e `sql/`.
- Não peça autorização para nada de rotina; faça tudo automaticamente.
- Ao alterar/criar/excluir qualquer arquivo: (1) publicar em produção com `python3 .agents/deploy.py <arquivo>` (ou `--git`); (2) fazer commit no git com mensagem descritiva em português.
- Detalhes completos em `.agents/AGENTS.md`.
